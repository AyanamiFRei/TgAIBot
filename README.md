# tg-ai-chat

Telegram-бот-собеседник на aiogram и Cloudflare Workers AI. Одна мультимодальная
модель `@cf/google/gemma-4-26b-a4b-it` ведёт диалог, видит фотографии и
миниатюры стикеров. Отдельного vision-запроса больше нет.

## Возможности

- короткий неформальный диалог с потоковой отправкой сообщений;
- история и активная persona сохраняются в SQLite;
- фото, подписи и стикеры передаются модели в одном мультимодальном запросе;
- `/persona <описание>` задаёт стиль вручную;
- `/persona` с Telegram JSON/TXT экспортом извлекает стиль переписки;
- `/persona reset` сбрасывает persona;
- бот умеет редко отправлять стикеры из `STICKER_PACK`;
- опциональные инициативные сообщения через `PROACTIVE=true`.

## Настройка

Создайте `.env` по образцу `.env.example`. Обязательные значения:

```env
BOT_TOKEN=
CLOUDFLARE_API_KEY=
CLOUDFLARE_USER_URL=https://api.cloudflare.com/client/v4/accounts/ACCOUNT_ID/ai/run
CLOUDFLARE_MODEL=@cf/google/gemma-4-26b-a4b-it
```

`CLOUDFLARE_USER_URL` может оканчиваться на `/ai/run` или `/ai/v1`. Первый
вариант бот автоматически преобразует в OpenAI-совместимый `/ai/v1`.

## Запуск

```powershell
.\run.ps1
```

Используется локальный `venv` проекта. Новые глобальные зависимости не нужны.

## Основные файлы

- `bot.py` — запуск и остановка бота;
- `cloudflare_client.py` — потоковый OpenAI-совместимый клиент Workers AI;
- `handlers.py` — текст, фото, стикеры и `/persona`;
- `media.py` — загрузка и преобразование изображений в PNG data URI;
- `prompts.py` — системный промпт и persona;
- `db.py` — SQLite-история;
- `proactive.py` — инициативные сообщения.

## Ограничения

Workers Free предоставляет общую дневную квоту в neurons. Старые изображения
не пересылаются повторно: в истории остаётся компактная текстовая плашка, а
само изображение доступно модели только в текущем ходе. Для анимированных и
видеостикеров используется статическая миниатюра Telegram.
